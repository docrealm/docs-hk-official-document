## 历史版本

**政府公文寫作手冊**
- 1996年5月，香港特別行政區政府法定語文事務署，《政府公文寫作手冊》試行版
- 1997年7月，香港特別行政區政府法定語文事務署，《政府公文寫作手冊》（修訂後的正式版）
- 2004年，香港特別行政區政府公務員事務局法定語文事務部，《政府公文寫作手冊》（第二版）
    > 法定語文事務署已經在2003年7月1日歸入公務員事務局，並改名為法定語文事務部。
- 2019年起，香港特別行政區政府公務員事務局法定語文事務部，《政府公文寫作手冊》（第三版）

- 1975年，《香港政府中文公文處理手冊》（油印版）
- 1986年，布政使司署第四號總務通告，附錄「白話文公函格式樣本」「白話文公函格式提要」
- 1991年，公務員訓練處語言訓練組（公務員培訓處），《常用中文公事格式及辭彙》（第四版）
- 1995年，《常用公文格式及樣本》
- 2000年9月，香港特別行政區政府法定語文事務署，《政府公文實例》

- 1997年，《法定語文條例》 [](https://www.elegislation.gov.hk/hk/cap5)
